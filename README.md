## 🧠 My Learning Method

1. **Feynman Technique** — Explain every concept in my own words (Telugu + English)
2. **DEP Method** in interviews — Definition → Example from BCP/ChatterBox → Problem it solves
3. **Link to real projects** — Every concept connected to BCP or ChatterBox
4. **Weekend projects** — Build something every weekend to reinforce the week's learning
5. **Mock interviews** — Weekly mock Q&A sessions from Week 3 onwards
